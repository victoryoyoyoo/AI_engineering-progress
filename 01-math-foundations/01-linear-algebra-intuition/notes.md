## Class 基本結構

```python
class Vector:              # 宣告一個類別（藍圖）
    def __init__(self, components):   # 建構子，物件被建立時自動執行
        self.components = components  # self = 這個物件自己（等於C++的this）
```

- `class`：宣告類別的固定關鍵字
- `__init__`：Python **固定名稱**（前後各2條底線），物件誕生時自動觸發
- `self`：每個方法的第一個參數，**強制慣例**（不是語法規定，但全世界都這樣寫）
- `self.xxx = xxx`：把資料**永久存到物件身上**；不加 `self.` 的變數只是**暫時的、方法跑完就消失**

## 運算子重載（讓 +, -, *, @ 可以用在自訂物件上）

| 符號 | 對應方法名 |
|---|---|
| `+` | `__add__` |
| `-` | `__sub__` |
| `*` | `__mul__` |
| `@` | `__matmul__`（matrix multiply 縮寫，矩陣乘法專用） |

- 這些「前後兩條底線」的名字叫 **dunder method**，是 Python **規定的固定名字**，底線數量錯了就失效
- `a + b` 會被 Python 自動翻譯成 `a.__add__(b)`——`+` 左邊 = `self`，右邊 = `other`
- 沒寫對應的 dunder method，那個符號用在你的物件上會直接報錯（`TypeError`）

## List comprehension（列表推導式）

```python
[運算式 for 變數 in 可走訪的東西]
```

- 是「一般 for 迴圈 + 建立新 list」的濃縮寫法
- 例：`[x*2 for x in [1,2,3]]` → `[2,4,6]`
- **注意順序是反的**：先寫「要算什麼」，再寫「資料從哪來」

## `zip()` — 內建函式

- 把兩個 list **同一位置**的元素配成一對一對
- `zip([1,2],[10,20])` → `(1,10)`、`(2,20)`
- 常搭配 `for a, b in zip(...)` 使用

## 內建函式清單（這課用到的）

| 函式 | 作用 |
|---|---|
| `list(x)` | 把 x 轉成 list 型態 |
| `len(x)` | 算 x 裡有幾個元素 |
| `sum(...)` | 把一堆數字加總 |
| `range(n)` | 產生 `0, 1, ..., n-1` 的連續數字，通常配合 for 迴圈控制跑幾次 |
| `isinstance(x, 型態)` | 判斷 x 是不是某個型態，回傳 True/False |

## f-string（字串格式化）

```python
f"我叫{name}"          # {} 裡放變數/運算式，會被換成實際值
f"{x:.4f}"              # :.4f = 顯示成浮點數，小數點後留4位
f"{x:10.4f}"            # 10 = 總寬度（不夠補空白），4 = 小數位數
```

- 前面要加 `f`，`{}` 裡的東西才會被特殊處理（不加 f，`{}` 只是普通文字）
- `{}` 裡可以放變數，也可以放任何運算式（`a+b`、`a.dot(b)` 都可以）

## 索引 `[數字]`

- `變數[數字]`：取出 list 裡「指定位置」的元素（從 0 開始算）
- 跟「建立新 list 用的中括號」`[1,2,3]` 是不同用途，看前面有沒有緊接著變數來分辨

## `if` 條件判斷

```python
if 條件:
    只有條件是 True 才執行這裡
```

## `return`

- 方法/函式執行到 `return X`，會**立刻結束**，把 `X` 交回給呼叫的地方
- 沒有 `return`，函式執行完會回傳 `None`（空值）

## NumPy 語法

```python
import numpy as np              # 載入 numpy 函式庫，as np 是取簡稱，之後打 np. 就好
a = np.array([1,2,3], dtype=float)   # 把 list 轉成 numpy 的陣列型態，dtype=float 指定用小數存
np.dot(a, b)                     # 內積，等同自己寫的 dot
np.linalg.norm(a)                # 算長度，等同自己寫的 magnitude
```

- `import ... as ...`：載入函式庫並取簡稱，不用每次打完整名字
- numpy 的陣列跟自己寫的 Vector 做的事一樣，只是別人已經寫好、速度更快

## 格式化補充

- `{x:10.4f}`：10 是總寬度（不夠補空白，內容比10長就不會被砍掉），4 是小數位數，兩個可以一起用也可以只用一個
- 只寫 `{x:10}` 不加 `f` 的話，數字太長不會被截斷，寬度只是「最小值」不是上限

## Python vs C++ 這課學到的差異

| 差異 | C++ | Python |
|---|---|---|
| 程式區塊 | `{ }` 大括號 | 縮排（空格） |
| 變數宣告 | 要先宣告型別 | 不用，動態型別（執行到才知道型別對不對） |
| this 指標 | 自動存在，不用寫 | 要自己明寫 `self`，且是第一個參數 |
| 建構子名稱 | 跟 class 同名 | 固定叫 `__init__` |
