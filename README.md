# AI Engineering Progress

My practice code and notes while going through the AI Engineering from Scratch course (https://github.com/rohitg00/ai-engineering-from-scratch).

Each phase folder matches the course's phase structure. Inside, each lesson gets its own subfolder:

- `practice.py` — my own hand-typed code
- `reference.py` — a reference/demo version I read through but didn't necessarily type myself (not tracked in this repo, kept local only)
- `numpy_version.py` — the same thing using NumPy instead of hand-rolled code, where relevant
- `notes.md` — what I actually learned that lesson, including an honest checklist against the official Learning Objectives (unchecked = not really covered yet, not hidden)

`LEARNING.md` at the root tracks overall progress across the whole course. `review-queue.md` tracks things I deferred and why, so nothing gets silently dropped.

Goal: build AI products, eventually start something with what I learn here.
