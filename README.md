# AI Engineering 學習紀錄

跟著 [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) 課程寫的筆記和練習。

## 內容

- `00-setup-and-tooling`：環境與工具篇，只有每課的 `reference.*`（Python、shell、Markdown、Docker 設定）
- `01-math-foundations`：數學基礎 14 課，每課有 `notes.md`（筆記）、`reference.py`（課程範例程式）、`practice.py`（自己打的練習，部分課沒有），另有 numpy / torch 對照版和 `images/` 裡的圖與畫圖腳本
- `02-ml-fundamentals`：還沒開始
- `NOTES_INDEX.md`：14 課筆記的索引

`reference.py` 取自課程（MIT 授權，https://github.com/rohitg00/ai-engineering-from-scratch），裡面的註解是我自己讀的時候加的。授權全文在 `LICENSE-course`。
