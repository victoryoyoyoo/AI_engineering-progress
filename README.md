# AI Engineering Progress

My practice code and notes while going through the AI Engineering from Scratch course (https://github.com/rohitg00/ai-engineering-from-scratch).

Each phase folder matches the course's phase structure. Inside, each lesson gets its own subfolder:

- `practice.py` — my own hand-typed code, no comments
- `reference.py` — a fully annotated reference/demo version, organized top-to-bottom by priority (core material first, then material I only need to understand, then anything deferred)
- a package-comparison file (`numpy_version.py`, `torch_version.py`, `sklearn_version.py`, etc., named after whichever library that lesson's Use It section actually calls for) — the same thing using the real library instead of hand-rolled code
- `notes.md` — what I actually learned that lesson: a term glossary, an honest checklist against the official Learning Objectives (unchecked = not really covered yet, not hidden), and the closing comprehension questions with full answers

`LEARNING.md` at the root tracks overall progress across the whole course. `review-queue.md` tracks things I deferred and why, so nothing gets silently dropped.

Goal: build AI products, eventually start something with what I learn here.
